## 📝 Thème Choisi

- *Thème :* Gestion d’un Centre Médical  
- *Description :*  
  Application backoffice permettant la gestion d’un centre médical à travers un tableau de bord.  
  L’application permet de gérer **Patients, Médecins, Rendez-vous, Prescriptions, Services**, avec toutes les fonctionnalités **CRUD**.  
  L’interface est dynamique, responsive et utilise **2 fichiers HTML seulement** (`index.html` pour login, `dashboard.html` pour le dashboard).
